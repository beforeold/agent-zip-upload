GitHub Zip Upload

An agent skill: upload a local .zip as a GitHub Release asset and get back a download link. GitHub is the backend; the agent uses its own credentials.

For agents

Read the skill:

https://beforeold.github.io/agent-zip-upload/SKILL.md

Quick start

curl -fsSL https://beforeold.github.io/agent-zip-upload/upload-zip.sh -o upload-zip.sh
chmod +x upload-zip.sh
./upload-zip.sh --repo OWNER/REPO file.zip   # prints JSON with "url"
